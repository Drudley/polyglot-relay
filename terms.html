2. The service

Polyglot Relay translates Discord messages. Depending on how it is set up, it does this:

  • on request, with the /translate command or the "Translate message" context-menu command,
  • when someone adds a flag reaction to a message,
  • automatically, between channels that a server administrator has paired.

Translations are produced by machine translation. This is either a translation engine we run ourselves or, for Premium, an AI translation provider (see the Privacy Policy). Machine translations can be wrong, incomplete, or misleading. Do not rely on them where errors could cause harm, for example in legal, medical, financial, or safety matters.
