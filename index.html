Talk across languages on Discord

Polyglot Relay translates messages right where your community chats: on demand, with a flag reaction, or automatically between channels. Message text is never stored.

Add to Discord

Asks only for: View Channels, Send Messages, Send Messages in Threads, Read Message History.

Features

/translate

Translate any text into any supported language. Only you see the result. Works in servers, in DMs, and as a personal app.

Right-click → Translate message

Translate someone's message into your Discord language in one click. Only you see it.

Flag reactions

React with 🇸🇪, 🇩🇪, 🇪🇸 … to post a short translation in the channel. It disappears again after two minutes.

Auto-translate channels

Mirror a channel into another language with /autotranslate. Everyone reads in their own language.

Safe by design

Never pings @everyone, @here, users, or roles. Has built-in loop protection and rate limits, and admin-only setup.

Private by default

Translation runs on our own self-hosted engine in Sweden. Message text is never stored, and we have no ads and no tracking. Privacy Policy.

Free vs Premium

Free

  • /translate, right-click translation, and flag reactions
  • 1 auto-translate channel pair per server
  • 20,000 characters per server per month (2,000 for personal installs)
  • Self-hosted standard translation engine
  • /usage shows what you have used this month

Premium coming soon

  • Higher-quality AI translation (generous fair-use allowance; the standard engine takes over after that)
  • Unlimited channel pairs, up to 10 target languages
  • Translations posted under the original speaker's name and avatar
  • Edits and deletions synced to translations (for 72 hours)
  • Server glossary for names and terms
  • Option to translate messages from other bots
